# Patient-Specific Proteomics FASTA Pipeline

Builds one custom FASTA database per patient for proteomics database search
(FragPipe / PEAKS / MSFragger), combining the full UniProt human reference
proteome with patient-specific variant peptides derived from WES data.

## Overview

Each patient FASTA contains:
- **Full UniProt reviewed human proteome** (~20,000 proteins)
- **Patient-specific variant peptides** derived from somatic variants
  identified by Mutect2 and annotated with VEP

Expression filtering (from RNA-seq) was not applied to the final FASTAs
to ensure sufficient database size for PeptideProphet scoring in FragPipe/PEAKS.

---

## Input files

### WES: filtered VCF files
The input VCF files (`<PATIENT>.final_filtered.vcf.gz`) are generated by the
**WES untreated pipeline** (see `1_untreated/1a_germline_filtering/`), specifically
as the final output of `filter_vcfs.sh` (Steps 1-3: PASS + VAF + gnomAD + PON filtering).
These files are saved in `$SCRATCH/WES_vcfs/filtered/`.

> Run the full WES germline filtering pipeline before running this pipeline.
> The VCF files must be named `<PATIENT>.final_filtered.vcf.gz`.

### RNA-seq: expression count matrix (optional)
The expression matrix (`exp.mat.tsv`) and sample metadata (`pdat.mat.tsv`) are
generated by **Stage 1 of the RNA-seq pipeline** (`rnaseq_pipeline.R`, run via
`run_rnaseq_preprocessing.sh`). These files are saved in the `results/` subfolder
of the RNA-seq project directory.

These files are only needed if running the optional expression filtering step
(`01_expression_filter.py`).

> See the RNA-seq repository for instructions on how to generate these files.
> The relevant output files are `results/exp.mat.tsv` and `results/pdat.mat.tsv`.

### UniProt reference FASTA
Downloaded directly from UniProt — see Step 1 below.

---

## Scripts

| Script | Purpose | Run order |
|--------|---------|-----------|
| `01_expression_filter.py` | Averages RNA-seq replicates per patient, outputs expressed gene lists (optional) | - |
| `02_generate_genemap.py`  | Downloads UniProt to ENSEMBL gene ID mapping from BioMart (run once) | 1 |
| `03_build_fasta.py`       | Builds patient-specific FASTAs from VEP VCFs + UniProt reference | 2 |
| `run_vep.sh`              | SLURM job script to run VEP on all patients in parallel | Before script 3 |

## Step-by-Step Usage

### Step 1 - Download UniProt human reference FASTA (once)
```bash
curl -o uniprot_human_reviewed.fasta \
  "https://rest.uniprot.org/uniprotkb/stream?query=reviewed%3Atrue%20AND%20organism_id%3A9606&format=fasta"

# Verify download
grep -c "^>" uniprot_human_reviewed.fasta  # expect ~20,000
```

### Step 2 - Generate UniProt to ENSEMBL gene map (once)
```bash
python 02_generate_genemap.py --outdir /path/to/proteomics_ref
```

### Step 3 - Annotate VCFs with VEP (per patient)

Input: `<PATIENT>.final_filtered.vcf.gz` files from `filter_vcfs.sh`
in the WES untreated pipeline (located in `$SCRATCH/WES_vcfs/filtered/`).

Submit as parallel SLURM jobs using `run_vep.sh`
(update paths inside the script first):

```bash
bash run_vep.sh
```

Or run manually per patient:
```bash
vep \
    --input_file  /path/to/vcfs/PDTO1.final_filtered.vcf.gz \
    --output_file /path/to/vep_annotated/PDTO1.vep.vcf \
    --vcf \
    --cache \
    --dir_cache /path/to/vep_cache \
    --assembly GRCh38 \
    --species homo_sapiens \
    --symbol \
    --canonical \
    --protein \
    --hgvs \
    --hgvsp \
    --sift b \
    --polyphen b \
    --offline \
    --force_overwrite \
    --fork 4
```

### Step 4 - Build patient-specific FASTAs
```bash
python 03_build_fasta.py \
    --uniprot /path/to/proteomics_ref/uniprot_human_reviewed.fasta \
    --genemap /path/to/proteomics_ref/uniprot_genemap.tsv \
    --vcf_dir /path/to/vep_annotated \
    --outdir  /path/to/patient_fastas \
    --flank   10
```

### Optional - Expression filtering from RNA-seq

Input: `exp.mat.tsv` and `pdat.mat.tsv` from `results/` in the RNA-seq pipeline
(generated by `rnaseq_pipeline.R`, Stage 1).

```bash
python 01_expression_filter.py \
    --exp        /path/to/rnaseq_project/results/exp.mat.tsv \
    --pdat       /path/to/rnaseq_project/results/pdat.mat.tsv \
    --outdir     /path/to/expression_filtered \
    --min_counts 10
```

### FASTA entry formats

Reference protein:
```
>sp|P04637|P53_HUMAN Cellular tumor antigen p53 OS=Homo sapiens ...
MEEPQSDPSVEPPLSQETFSDLWKLLPENNVLSPLPSQAMDDLMLSPDDIEQWFTEDP...
```

Variant peptide:
```
>VAR_PDTO1_TP53_ENSP00000269305.4:p.Arg175His patient=PDTO1 gene=TP53 consequence=missense_variant hgvsp=... [VARIANT_PEPTIDE]
VVRCPHHERCSDSDGLAPPQHLIRVEGNLH
```

## Notes

- VCF files must be **properly filtered** before input (only PASS variants are used)
- VEP must be run with `--canonical` to use one representative transcript per gene
- The `--flank` parameter controls variant peptide size (default: 10 AA on each side)
- Variant peptides shorter than 7 AA are excluded (below typical MS detection threshold)
- Patient IDs in `PATIENTS` (script 3) and `PATIENT_MAP` (script 1) must match
  the VCF filenames and sample sheet respectively — update these for your dataset
